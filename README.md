# VejasAuth

This is a Yubikey clone/alternative to save passkeys. I mainly made it so I could have a passkey key for the computers at my school as writing passwords is annoying.

This auth key includes:
- The RP2350 microcontroller
- 128mbit storage
- 2 buttons
- 5 GPIO outputs
- a neopixel
- a USBC port
- a USBA port
